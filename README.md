# Habib's Portfolio

A responsive, single-file portfolio for Habib. It uses plain HTML, CSS, and JavaScript, so there are no dependencies, accounts, databases, or build steps.

## Preview

Open `index.html` in a browser. The page works as a local file; a web server is not required for previewing it.

## Update the content

1. Open the page and select the pencil button in the lower-right corner.
2. Edit your details, skills, links, and projects in the visual editor.
3. Select **Save changes** to preview the updates in that browser.
4. Select **Download updated website** to download a portable HTML file containing those edits.
5. Rename the downloaded file to `index.html` if needed, then replace the existing `index.html` on your web host.

Browser saves are local to that browser and device. They do not change a published website. Publish the downloaded HTML file whenever you want your saved changes to appear online. Keep a copy of the previous file as a backup.

Skills are entered as comma-separated names. Add projects one at a time; project screenshots and demo/source links are optional. For a profile image, paste a public HTTPS image URL you control. Blank social fields stay hidden. The starter page intentionally contains no fabricated social accounts or completed projects.

## Publish

This is a static website. Upload `index.html` (or the exported HTML renamed to `index.html`) to any static web host that serves HTML files. No server-side form is included because no form service was configured; visitors can contact you through the social or email links you add.

The page title, description, and favicon are included in the HTML. Google Fonts are loaded from Google when available; the page falls back to local sans-serif fonts if they are not.
